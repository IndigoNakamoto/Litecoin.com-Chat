# What is Litecoin?

Litecoin is a peer-to-peer cryptocurrency. The ticker symbol is LTC. Charlie Lee released it in October 2011 as an open-source project derived from Bitcoin's code, with different parameters so blocks arrive faster and mining uses a different proof-of-work function. Units are divisible to eight decimal places. The smallest unit is the litoshi, one hundred-millionth of one LTC.

Litecoin's chain is secured by proof of work. Miners run the Scrypt hashing algorithm and compete to publish the next block. The target interval is 2.5 minutes, about four times shorter than Bitcoin's ten minutes. The block subsidy and transaction fees are the only protocol payments. Holding LTC in a wallet does not earn a protocol reward, and Litecoin Core has no yield feature for locking or delegating coins.

## How Litecoin differs from Bitcoin

Litecoin and Bitcoin are both public proof-of-work chains with a capped supply and no central issuer. They differ in the parameters a user actually feels. Litecoin targets a new block every 2.5 minutes; Bitcoin targets one every 10 minutes. Litecoin's maximum supply is 84 million LTC; Bitcoin's is 21 million BTC. Litecoin mining uses Scrypt; Bitcoin mining uses SHA-256, so the hardware pools are not the same. Litecoin also added MimbleWimble extension blocks (MWEB) as an opt-in way to send confidential amounts, which Bitcoin's base layer does not have. Neither chain lets a sender, an exchange, or the Litecoin Foundation cancel a payment once it is in a block.

## What Litecoin is not

Litecoin is not a company, and owning LTC is not a share in the Litecoin Foundation. The software is open source. Anyone can run a node, mine, or hold coins without an account. Price targets, buy and sell advice, and tax conclusions are outside what this description covers. A wallet balance is not a bank deposit and has no protocol interest.
